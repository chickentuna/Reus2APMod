## Install

**1. BepInEx** — download **BepInEx 5, `win_x64`** and unzip it into the game folder, next to
`Reus 2.exe`. Run the game once so BepInEx creates its folders, then close it.

<https://github.com/BepInEx/BepInEx/releases/download/v5.4.23.5/BepInEx_win_x64_5.4.23.5.zip>

**2. The mod** 

Unzip `Reus2Archipelago.zip` into the same game folder. (there should be a new dll in `BepInEx/plugins/`).

**3. The apworld** 

Double click `reus2.apworld` or simply copy it to your Archipelago install's `custom_worlds/` folder.

(It works on Linux with the linux bepinex release + `WINEDLLOVERRIDES="winhttp=n,b" %command%` in the steam launch options).

## Playing

Press **F1** to toggle the connection panel, should open by itself on the main menu if you installed the mod right. Details are remembered for next time you open the game.

Each seed and slot is played on its own profile, so existing profiles are not affected.

## What is randomised

### Locations

Building Biotica and/or triggering all the synergies on a Biotica.

City Quest Rewards.

Purchases in the Drafts Shop.

### Items

Individual Biotica and/or Apex + Cohorts.

Unlockables (terraforming powers, shops, Final Eras, etc.)

Giants.

Biomes.

Charges (including Border Boost and Eon Boost).

## Goal

The goal is to build/synergize a number of different biotica.

`max_biotica_level` shortens a game.
